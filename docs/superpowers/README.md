# Piani e specifiche storiche

I file in `plans/` e `specs/` conservano l'evidenza di lavori progettati o
completati. Non sono backlog, roadmap né descrizione dello stato corrente.

Prima di aprirli:

1. usa `docs/ROADMAP.md` per capire cosa è attivo;
2. usa `docs/CONTEXT.md` per lo stato corrente;
3. apri un piano storico solo se il task cita quel filone o richiede le sue
   decisioni di dettaglio;
4. verifica sempre il piano contro codice, ADR e documentazione canonica.

Un piano completato può contenere versioni, risultati, store o procedure ormai
superati. Non promuoverli a requisiti correnti senza verifica.
